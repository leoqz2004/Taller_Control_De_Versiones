# Sistema de Gestión de Clientes

## Descripción

Proyecto Integrador I desarrollado para gestionar el registro y consulta de clientes mediante una aplicación en Python.

## Problema

El sistema permite almacenar información básica de clientes de manera organizada, evitando el registro manual de los datos.

## Integrantes y roles

- Integrante 1: Desarrollo del sistema
- Integrante 2: Base de datos
- Integrante 3: Pruebas y documentación
- Integrante 4: Revisión e integración

## Tecnologías

- Python
- SQLite
- Git
- GitHub
- Visual Studio Code
